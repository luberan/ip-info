Privacy and data sources

The page processes public IP addresses and available technical connection details. Your browser contacts ipify directly to detect IPv4 and IPv6 independently. The Cloudflare Worker sends detected addresses to IPinfo Lite for ASN, network organization, and country information. Reverse DNS queries use Cloudflare DNS over HTTPS.

The application has no accounts, cookies, analytics, or tracking scripts. It does not store addresses in its own database or application IP logs. Data is kept on the page only while it is open. Infrastructure providers Cloudflare, ipify, and IPinfo may process technical connection information under their own policies. Disabling Worker logging and tracing does not mean that infrastructure providers process no operational data.
